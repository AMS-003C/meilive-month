A

投前必备 · 起量秘籍

必做 A1 · 创意 — 节点贯穿五段融入 头部大场创意 CTR 环比 +13%
直播间创意按"开头炸 / 中段留 / 报价值 / 促单快 / 曝光广"五段分段融入大场元素,每段都必须有"机制/场景/价值/福利/曝光"五要素之一。
  • ① 开头炸:炸裂机制开场,85折补贴 + 平台券 + 黄金三秒抓人(如"现在赶大场")
  • ② 中段留:场景化带大场(种草留人),把"日常品"嵌入"大场场景"
  • ③ 报价值:明星/口播报价,"直降千元到手价" — 信任放大
  • ④ 促单快:营销组件强调,组件大场表达,挂钩福利,缩短决策
  • ⑤ 曝光广:AIGC resize 模板,多版位凸显,公私域协同
💡 核心收益:头部直播间大场类型创意 CTR 环比 +13%;有消耗创意数 翻倍 +46%;直播间商品点击率环比 +35%
必做 A2 · 文案 — 大场 + 具体场景/产品利益
节点文案 = 大场 + 具体场景 + 产品利益 三件套,避免"大场+促销"的空话式文案。
优质高 CTR 文案 Case 大场 具体场景 产品利益
  • 大场 促销+卖点融合:果蔬净化机"流速淳淳流清",一键净享健康安心;挂烫机"大场老婆抢的",熨完衬衫穿三天
  • 大场 情感+人群向:按摩仪"给爸爸买一个",不担心腰酸问题;炒锅"求购爸爸,就送它",无痛又良众
  • 大场 场景化关联:便携风扇"大场放假出门带遮阳伞还是防晒衣",当然要带这个风扇,省心又凉爽

必做 A3 · 直播间运营 & 话术
直播间主播话术设计框架(开图 1,4 轮讲解核心 + 开场话术 + 留人技巧): 需要重点注意:
  1. 场景的特殊福利价值
    通过主播 KT 版等方式标明目前大场特惠机制,或赠送 xxx 专属福利
    • KT 版呈现:主播身后立牌/贴片用大字号标出"今日下单送 XX / 限时特惠 X 折",用户进直播间 3 秒内即可识别"大场专属"
    • 话术模板:"今天来我直播间,大场专享,买 XX 送 XX,这个价格全网只有这里有"——反复强化稀缺感
    • 参考案例:欧洛德总裁驾到专属福利、友望 10 周年店庆 1 折优惠明示、聚量"送沥水篮"组合
  2. 大场贴片
    清晰展示活动主题 + 大场活动 + 限时特惠,刺激即时下单
    • 贴片三要素:顶部 品牌背书 + 中部 大场场景 + 底部 核心利益点(如"鹅选美好生活节 / 清凉节大场 / 限时特惠 XX元")
    • 封面对齐:高清、色彩明亮、富有视觉冲击力,封面点击率直接影响私域分享带来的自然流
    • 历史验证:三禾、太力、坂田川、聚量挂载官方贴片后,客户自述场观较未挂载 +30%
  3. 特殊形式策划(总裁进播 / 现场走播)
    历史实测人均观看 +10%、进播时段环比 +110%,量级环比带动效果均较好
    • 总裁/创始人进播:邀请品牌创始人/总裁/营销总裁亲临,讲品牌故事与产品初衷,停留时长与转化率显著提升
    • 现场走播:主播走出直播间到展会/工厂/仓库现场,让用户"看到产品诞生地",信任感倍增
    • 参考案例:欧洛德厂长驾到、张小泉林永健代言走播、太力百货展现场走播、迈巴勒展会走播

C

产品工具加持(可选)

可选 C1 · 大场速推(对内配置) 3C 头客展播期额外竞得消耗 3w+
为什么建议配置:大场时间短,要求短时间快速起量;大场速推策略生效后,专场直播流速比平常更快,短时间获取更大消耗规模。
  • 策略激进程度:可选 速度优先 或 成本优先(对成本约束严格时选成本优先)
  • 适合客户:单场预算 >10w · 在线人数 >150 · 能放宽 ROI 20%+(自然流占比 10%+ 弥补)
  • 盯盘操作:助推生效期间 不做主动放量动作(提价/一键起量等);ROI 降低可适当降价 3-5 元;超成本 20%+ 协商是否关停
📋 大场速推申请模板(填写后联系行业运营) # 示例:直播时段 10:00-16:00,加速放量时段 10:00-14:00 1、需求提出方:客户主体名称 2、账户id:例如 54544614 3、生效时间及系数:2025/8/26 10:00-14:00#1.3, 14:00-16:00#1.2 4、激进程度:成本优先 / 速度优先 5、是否对新广告加速:是 / 否 ⚠️ 通过运营工具干预后,存在超成本风险,「不保成本且不再赔付」

💡 3. 测试效果：目前在投客户直播间专场放量工具广告条均消耗 ARPU 提升 2 倍+
